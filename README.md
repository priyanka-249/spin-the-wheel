# 🎡 Spin the Wheel

A simple Flutter application that helps users make random decisions using an interactive spinning wheel.

## 📱 About the Project

Spin the Wheel allows users to choose between different options using a visual wheel. The current version focuses on building the basic user interface and wheel layout using Flutter widgets.

The project is being developed incrementally as part of the **UI Design – Flutter Lab**.

## ✨ Current Features

* 🎡 Wheel interface
* 🍕 Multiple options displayed on the wheel
* 🔘 Spin button UI
* 📱 Basic Flutter layout
* 🎨 Simple custom wheel design

## 🛠️ Technologies Used

* Flutter
* Dart
* Android Studio
* Chrome

## 🚧 Project Status

**Currently in development.**

The current version contains the basic UI and static wheel. Future versions will add functionality such as wheel animation, random selection, dynamic options, and other Flutter concepts covered during the laboratory course.

## ▶️ How to Run

Make sure Flutter is installed, then run:

```bash
flutter pub get
flutter run -d chrome
```
